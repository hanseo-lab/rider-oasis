# 경기 안심 로드 - 풀스택 애플리케이션

**이동노동자를 위한 사계절 안전 경로 탐색 서비스**

## ✨ 주요 기능

### 1. 🔐 사용자 인증
- 회원가입 / 로그인 (JWT 토큰 기반)
- 자동 로그인 유지 (LocalStorage)
- 보안된 API 통신

### 2. 🗺️ 메인 지도
- 경기도 폭염 위험 지역 시각화 (붉은색)
- 그늘/녹지 지역 표시 (초록색)
- 무더위 대피시설 마커 (파란색)

### 3. 🚀 경로 탐색
- **출발지/도착지 검색**: 주소 입력으로 위치 검색
- **최단 경로 vs 그늘 경로 비교**
  - 최단 경로: 가장 빠른 경로
  - 그늘 경로: 폭염 노출 최소화 (A* 알고리즘)
- **실시간 경로 비교**
  - 거리, 시간, 그늘 비율, 폭염 노출도 비교
  - 대피시설 개수 표시
- **지도에 경로 표시**: 선택한 경로를 지도에 시각화

## 🏗️ 기술 스택

### Frontend
- React 19 + TypeScript
- Vite (빌드 도구)
- React Router (라우팅)
- Zustand (상태 관리)
- Axios (HTTP 클라이언트)
- Leaflet (지도)
- Tailwind CSS (스타일링)

### Backend
- Spring Boot 3.2.1 + Java 17
- Spring Security + JWT
- JPA/Hibernate
- H2 Database (개발)
- Gradle

### API
- 경기기후 플랫폼 API (404개 레이어)
- Nominatim (주소 검색)

## 🚀 실행 방법

### 1. 백엔드 서버 실행

```bash
# Windows
.\gradlew.bat bootRun

# Mac/Linux
./gradlew bootRun
```

서버가 `http://localhost:8080/api`에서 실행됩니다.

**H2 Console**: http://localhost:8080/api/h2-console
- JDBC URL: `jdbc:h2:mem:rideroasis`
- Username: `sa`
- Password: (비어있음)

### 2. 프론트엔드 서버 실행

```bash
npm run dev
```

서버가 `http://localhost:5173`에서 실행됩니다.

## 📱 사용 방법

### Step 1: 회원가입/로그인
1. 브라우저에서 `http://localhost:5173` 접속
2. "회원가입" 클릭
3. 사용자명, 이메일, 비밀번호 입력
4. 자동으로 로그인되어 메인 지도로 이동

### Step 2: 메인 지도 확인
- 경기도 지역의 폭염 위험 지역 (붉은색)
- 그늘/녹지 지역 (초록색)
- 대피시설 (파란색 마커)
- 상단 네비게이션에서 "경로 탐색" 클릭

### Step 3: 경로 탐색
1. **출발지 입력**
   - 주소 입력 (예: "수원역")
   - Enter 또는 검색 버튼 클릭

2. **도착지 입력**
   - 주소 입력 (예: "성남시청")
   - Enter 또는 검색 버튼 클릭

3. **경로 탐색 시작** 버튼 클릭

### Step 4: 경로 비교 & 선택
- **최단 경로 (파란색)**
  - 거리: 가장 짧음
  - 시간: 가장 빠름
  - 폭염 노출: 높을 수 있음

- **그늘 경로 (초록색)** - 추천!
  - 거리: 약간 더 멀 수 있음
  - 시간: 약간 더 걸릴 수 있음
  - 그늘 비율: ⬆️ 높음
  - 폭염 노출: ⬇️ 낮음

5. **원하는 경로 클릭하여 선택**
6. 지도에서 선택한 경로 확인

## 🔧 API 엔드포인트

### 인증
- `POST /api/auth/signup` - 회원가입
- `POST /api/auth/login` - 로그인

### 경로
- `POST /api/routes` - 경로 생성
- `GET /api/routes` - 내 경로 목록
- `DELETE /api/routes/{id}` - 경로 삭제

## 🧪 테스트 시나리오

### 1. 회원가입 & 로그인
```bash
# 회원가입 요청
curl -X POST http://localhost:8080/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "username": "rider01",
    "email": "rider01@example.com",
    "password": "password123",
    "nickname": "배달의민족"
  }'
```

### 2. 경로 탐색
```bash
# 로그인 후 받은 토큰으로
curl -X POST http://localhost:8080/api/routes \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "routeName": "수원 -> 성남",
    "startLat": 37.2636,
    "startLng": 127.0286,
    "startAddress": "수원역",
    "endLat": 37.4201,
    "endLng": 127.1262,
    "endAddress": "성남시청",
    "routeType": "SHADE_OPTIMIZED"
  }'
```

## 🚨 문제 해결

### CORS 오류
백엔드 `CorsConfig.java`에서 프론트엔드 URL 확인:
```java
configuration.setAllowedOrigins(Arrays.asList(
    "http://localhost:5173",  // Vite
    "http://localhost:3000"
));
```

### JWT 토큰 만료
- 토큰 유효기간: 24시간
- 만료 시 자동으로 로그인 페이지로 이동
- 다시 로그인하면 새 토큰 발급

### 주소 검색 안 됨
- Nominatim API 사용 (무료, 제한 있음)
- "경기도 XX시" 형식으로 검색하면 더 정확

### 경로가 이상하게 나옴
- A* 알고리즘이 임시 데이터 사용 중
- 실제 경기기후 API 데이터와 연동 필요
- `AStarPathfinder.java`의 `calculateShadeScore()`, `calculateHeatScore()` 메서드 개선 필요
